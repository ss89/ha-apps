## Apps

### OpenEVT
Click this link:

[![Go to app installation page](https://my.home-assistant.io/badges/supervisor_addon.svg)](https://my.home-assistant.io/redirect/supervisor_addon/?addon=fe3706e6_openevt&repository_url=https%3A%2F%2Fgithub.com%2Fss89%2Fha-apps)

After installing it, go to the configuration tab and set the inverters address and serial number.

Finally hit start and consider letting it start up on boot and enable watchdag to have it restart if there are any issues.
